# Schedule Plan 4: NVMe Warm-Up Pre-Read

**Phase:** 1 (Measurement & Quick Wins)
**Priority:** Medium
**Effort:** Low (2 hours)
**Risk:** Low
**Impact:** Drops 2-5 seconds of latency from the initial prefill token (Token 1).

## Objective
The very first token generated by Vaayu (the prompt ingestion phase) is always disproportionately slow because the NVMe controller's internal DRAM cache and the OS I/O subsystems are completely cold. By triggering a background pre-read of the first few layers immediately after model initialization, we can prime the read-ahead logic before the user even submits a prompt.

## Context for the Coding Agent
We want to spin up a daemon thread at the end of the `VaayuBaseModel` constructor that sequentially reads the first ~10 layers of the model into a dummy buffer and throws the data away. The goal is to touch the disk blocks, not keep the data.

## Implementation Steps

### Step 1: Implement `_warmup_nvme()`

**File to modify:** `vaayu/vaayu_base.py`

Add a private method to the `VaayuBaseModel` class:

```python
import threading
import torch
import os

    def _warmup_nvme(self):
        """
        Pre-read the first few layers to warm up the NVMe controller's
        internal DRAM cache and read-ahead logic. This reduces Token 1 latency.
        Reads are thrown away — the purpose is to prime the NVMe hardware.
        """
        if not hasattr(self, '_layer_paths') or not self._layer_paths:
            return
            
        def _do_warmup():
            warmup_layers = min(10, len(self._layer_paths))
            # Allocate a temporary pinned buffer large enough for 1 layer (~1.7 GB max)
            buf = torch.empty(1700 * 1024 * 1024, dtype=torch.uint8, pin_memory=True)
            
            try:
                import vaayu_rust
                has_rust = hasattr(vaayu_rust, 'io_uring_read_into')
            except ImportError:
                has_rust = False
            
            for i in range(warmup_layers):
                path = self._layer_paths[i]
                try:
                    file_size = os.path.getsize(path)
                    if has_rust:
                        # Always use O_DIRECT=True for warmup: goal is to prime the NVMe
                        # controller's internal DRAM cache, not fill the Linux page cache.
                        # Signature: (path, offset, length, buf_ptr, queue_depth, use_direct_io)
                        # After Plan 5 adds use_direct_io param; before Plan 5, use 5-arg form.
                        try:
                            vaayu_rust.io_uring_read_into(path, 0, file_size, buf.data_ptr(), 32, True)
                        except TypeError:
                            # Plan 5 not yet applied — fall back to 5-arg form
                            vaayu_rust.io_uring_read_into(path, 0, file_size, buf.data_ptr(), 32)
                    else:
                        with open(path, 'rb') as f:
                            f.readinto(buf.numpy())
                except Exception as e:
                    print(f"[Vaayu] Warm-up aborted on layer {i}: {e}")
                    break  # warmup is best-effort
            
            del buf
            print(f"[Vaayu] NVMe warm-up complete ({warmup_layers} layers pre-read)")
        
        # Run in background so it doesn't block model init or prompt intake
        t = threading.Thread(target=_do_warmup, daemon=True)
        t.start()
        self._warmup_thread = t
```

*Note: Ensure `self._layer_paths` exists. If the layers are resolved dynamically, use the actual list of safetensor file paths for the model.*

### Step 2: Trigger Warmup

At the end of the `from_pretrained()` process (either in `auto_model.py` or the bottom of `__init__` in `vaayu_base.py`), call `self._warmup_nvme()`.

```python
        # Near the end of VaayuBaseModel.__init__
        self._warmup_nvme()
```
